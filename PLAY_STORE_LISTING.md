## 🔒 Security & Privacy Practices (Complying with POPIA & Play Store)

1.  **Zero Cloud Collection:** All user profiles, lesson statuses, streak records, and simulated chats remain strictly local inside a Room SQLite database on the device. No data is harvested, sold, or sent to a third party.
2.  **POPI Act Compliant:** Complies with the South African Protection of Personal Information Act. Private community records and refer-a-student names are encrypted locally.
3.  **Local Sandbox Sandbox Isolation:** Code execution happens in a local container; no device file access permissions are requested in `AndroidManifest.xml`.
